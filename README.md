# 인노바드 재고·배송 관리 — 자동 업데이트

이 저장소는 Windows 프로그램 **인노바드 재고·배송 관리** (주식회사 어베인그룹)의 **새 버전 실행 파일만** 올리는 곳입니다.

- 프로그램이 이 저장소의 **Releases 최신 버전**을 스스로 확인해 받아 바꿉니다. 사람이 내려받을 필요는 없습니다.
- 릴리스마다 파일 2개: `인노바드재고관리.exe` (실행 파일) · `인노바드재고관리.exe.sha256` (SHA-256 확인값).
  프로그램은 받은 파일의 SHA-256 이 맞을 때만 교체합니다.
- 릴리스 본문 = 변경 내용. 첫 줄이 `[필수]` 이면 필수 업데이트입니다.
- 이 저장소에는 **소스 코드 · 데이터 · 키 · 서버 주소가 없습니다.** 프로그램 설정(서버 주소·키)은 각 PC 에만 암호화되어 저장됩니다.

문의: 주식회사 어베인그룹
